## 2. Какие данные обрабатываются

### 2.1. Указываемые Пользователем

| Данные | Обязательность |
|---|---|
| Логин | обязательно |
| Адрес электронной почты | обязательно |
| Пароль — хранится только в виде необратимого хеша | обязательно |
| Отображаемое имя, аватар, статус, раздел «О себе» | по желанию |
| HTML-визитка и загруженные для неё изображения | по желанию |
| Содержимое сообщений и вложений | возникает при использовании |

### 2.2. Собираемые автоматически

| Данные | Зачем |
|---|---|
| **IP-адрес** | доставка сообщений, защита от подбора паролей, ограничение частоты запросов, расследование инцидентов |
| **User-Agent** — браузер, его версия, операционная система | совместимость интерфейса, распознавание входа с незнакомого устройства, обнаружение автоматизированных обращений |
| Дата, время и результат входа | безопасность аккаунта, список активных сессий для самого Пользователя |
| Идентификатор сессии | поддержание авторизованного состояния |
| Технические журналы сервера | диагностика неисправностей |

Геолокация не собирается. Сторонние рекламные и аналитические трекеры не используются.
Рекламные профили не строятся.

### 2.3. Специальные категории

Данные о здоровье, религиозных убеждениях, политических взглядах, национальности
и интимной жизни целенаправленно не запрашиваются и не обрабатываются. Если Пользователь
размещает такие сведения по собственной инициативе, они обрабатываются как часть его
Контента.

1. Работа Сервиса и доступ к его функциям.

Для иных целей, включая любые рассылки рекламного характера, данные не используются.

## 4. Правовые основания

**По 152-ФЗ:** согласие Пользователя, выраженное при регистрации (п. 1 ч. 1 ст. 6);
исполнение договора, стороной которого является Пользователь, — Пользовательского
соглашения (п. 5 ч. 1 ст. 6); исполнение обязанностей, возложенных законом
(п. 2 ч. 1 ст. 6).

**По GDPR — для Пользователей из Европейской экономической зоны:**

- ст. 6(1)(b) — исполнение договора: логин, почта, содержимое сообщений;
- ст. 6(1)(f) — законный интерес: IP-адрес и User-Agent для безопасности Сервиса
  и защиты Пользователей от злоупотреблений. Данные не используются для профилирования
  и рекламы, объём минимален, срок хранения ограничен — на этом основании интерес
  считается не перевешивающим права субъектов;
- ст. 6(1)(a) — согласие: необязательные данные профиля.

## 5. Сколько хранится

| Данные | Срок |
|---|---|
| Данные аккаунта | пока аккаунт существует |
| Сообщения | пока не удалены Пользователем или пока существует аккаунт |
| **IP-адрес и User-Agent в журналах входа** | 12 месяцев, далее удаляются автоматически |
| Технические журналы сервера | 90 дней |
| Записи о блокировках и жалобах | 3 года |

После удаления аккаунта данные удаляются в течение 30 дней, кроме записей о нарушениях,
необходимых, чтобы заблокированный Пользователь не зарегистрировался заново.

## 6. Кому данные передаются

Данные не продаются и не передаются третьим лицам для их собственных целей.

Технически к серверу имеет доступ хостинг-провайдер, предоставляющий Администратору
виртуальный сервер (VPS). Он не обрабатывает данные по поручению Администратора и не имеет
права использовать их в своих целях, но физически владеет оборудованием, на котором
они хранятся.

Уполномоченным органам данные передаются только по законному мотивированному запросу.

## 8. Как данные защищены

- Пароли хранятся в виде хеша с солью (argon2/bcrypt); исходные пароли Администратору
  неизвестны.
- Передача данных — только по HTTPS.
- Загружаемые изображения перекодируются, метаданные, включая координаты съёмки из EXIF,
  удаляются автоматически.
- Пользовательский HTML в профилях исполняется в изолированной среде на отдельном домене
  и лишён доступа к данным Сервиса и к внешней сети. В частности, это означает, что автор
  оформления профиля **не может** узнать IP-адрес или User-Agent тех, кто его
  просматривает.
- Административные действия записываются в журнал.
- О ставшей известной утечке, создающей риск для Пользователей, Администратор сообщает
  затронутым Пользователям в интерфейсе Сервиса и на указанную ими почту в возможно
  короткий срок.

Проект ведётся частным лицом на арендованном сервере. Уровень защиты соответствует
разумным техническим мерам, но не может сравниться с инфраструктурой крупного сервиса.
Это стоит учитывать при выборе того, что писать в Сервисе.

### 9.1. По 152-ФЗ

- получить подтверждение факта обработки и сведения о ней;
- требовать уточнения, блокирования или уничтожения неполных, устаревших, неточных
  или незаконно полученных данных;
- отозвать согласие на обработку;
- обжаловать действия Администратора в Роскомнадзоре или в суде.

### 9.2. Дополнительно по GDPR — для субъектов из ЕЭЗ

- доступ к данным (ст. 15), исправление (ст. 16), удаление (ст. 17);
- ограничение обработки (ст. 18);
- переносимость — выгрузка в машиночитаемом виде (ст. 20);
- возражение против обработки на основании законного интереса (ст. 21);
- не быть объектом решения, основанного исключительно на автоматизированной обработке
  (ст. 22). Таких решений не принимается: блокировки применяет человек;
- подать жалобу в надзорный орган страны своего проживания.

### 9.3. Как воспользоваться

Написать на qwillproject@gmail.com с адреса почты, указанного в аккаунте. Ответ — в течение 30 дней.

сообщений, удаление аккаунта, просмотр и завершение активных сессий.

**Отзыв согласия** влечёт удаление аккаунта: без обработки логина, почты и IP-адреса

Используются только технически необходимые:

| Назначение | Что хранится |

Технически необходимые cookie отключить нельзя — без них вход в аккаунт невозможен.
