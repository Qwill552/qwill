Qwill — бета-версия для Windows

В архиве четыре файла:

  Установить Qwill.bat    запустите его, это всё, что нужно
  Qwill-Setup-...exe      сам установщик
  qwill-code-signing.cer  открытая часть сертификата, которым подписан установщик
  ПРОЧИТАЙ МЕНЯ.txt       этот файл


КАК УСТАНОВИТЬ

  1. Распакуйте архив целиком в любую папку.
     Запускать прямо из архива нельзя.
  2. Запустите «Установить Qwill.bat».
  3. Windows спросит разрешение администратора — подтвердите.
  4. Установщик запустится сам, дальше ничего делать не нужно.


ЗАЧЕМ НУЖЕН СЕРТИФИКАТ

  Qwill подписан собственным сертификатом, а не покупным. Windows такой
  сертификат не знает: при установке он ругается, а будущие обновления
  отказывается применять вовсе — приложение будет писать, что обновление
  не проверилось.

  Файл .bat добавляет сертификат Qwill в доверенные на вашем компьютере.
  После этого Windows доверяет программам, подписанным Qwill: установка
  проходит тихо, а обновления приходят сами.

  Это разовое действие. Следующие версии приложение скачает и поставит
  само, архив больше не понадобится.


ЕСЛИ .BAT ЗАПУСКАТЬ НЕ ХОЧЕТСЯ

  Установщик можно запустить напрямую — Qwill встанет и будет работать.
  Но каждое обновление придётся ставить руками, скачивая с сайта новый
  установщик.
