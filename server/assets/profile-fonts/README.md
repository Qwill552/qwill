# Шрифты HTML-визитки

Сюда кладутся `.woff2`. Папка сканируется при старте сервера, семейства появляются в списке
редактора без правки кода.

- имя семейства = имя файла без расширения: `Inter.woff2` → `font-family: "Inter"`;
- начертание — суффиксом через дефис: `Inter-Bold.woff2` → то же семейство, `font-weight: 700`.
  Распознаются `Thin`, `ExtraLight`, `Light`, `Regular`, `Medium`, `SemiBold`, `Bold`,
  `ExtraBold`, `Black` и `Italic` (в том числе слитно: `Inter-BoldItalic.woff2`);
- нераспознанный суффикс даёт отдельное семейство с полным именем файла: `PT-Sans.woff2` →
  `font-family: "PT-Sans"`;
- имя файла — только латиница, цифры, точка, дефис и подчёркивание. Другое расширение или
  другие символы игнорируются, в лог при старте уходит предупреждение.

Блок `@font-face` собирается сервером и вставляется в `<head>` документа визитки
(`server/src/http/cardHost.ts`). Пользователю писать `@font-face` не нужно — достаточно
`font-family`.

После добавления файла сервер нужно перезапустить.
